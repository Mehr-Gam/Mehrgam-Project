# MehrGam Backend Starter

Express.js backend starter for the MehrGam project.

## Setup

```bash
npm install
cp .env.example .env
npm run dev
```

Then test:

```txt
GET http://localhost:5000/api/v1/health
```

## Structure

```txt
src/
  app.js
  server.js
  config/
  middlewares/
  modules/
  utils/
```
